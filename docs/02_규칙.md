# 여명 시스템 — 규칙

가볍고 이야기 중심적인 **2d6 기반** 시스템입니다. 판정은 대부분 주사위 두 개를 굴려 능력치를
더하면 끝. 규칙보다 "무엇을, 왜 하려는가"를 먼저 말하는 게임입니다.

> 진행 도구 [`../tools/index.html`](../tools/index.html) 에 주사위 판정기·캐릭터 시트가 들어있어
> 아래 규칙을 자동으로 처리해 줍니다.

---

## 1. 기본 판정

무언가 결과가 불확실하고 실패가 흥미로울 때만 굴립니다.

```
2d6 + 능력치 수정치  (+ 상황 보정)
```

| 결과 | 판정 | 의미 |
|------|------|------|
| **10 이상** | 성공 | 원하는 대로 된다. |
| **7 ~ 9** | 부분 성공 | 되긴 되는데 대가·합병증·선택이 따른다. |
| **6 이하** | 실패 | 뜻대로 안 된다. GM이 상황을 악화시킨다. (경험은 얻음) |

- **어드밴티지/디스어드밴티지**: 상황이 유리하면 +1, 불리하면 −1 (최대 ±2).
- **협력**: 다른 PC가 실질적으로 도우면 굴리는 사람이 +1.

## 2. 능력치 (4종)

| 능력치 | 읽기 | 담당 영역 |
|--------|------|-----------|
| **체(體)** | 체 | 몸, 완력, 버티기, 위험을 무릅쓰기 |
| **지(知)** | 지 | 지식, 조사, 추론, 준비 |
| **감(感)** | 감 | 직관, 오감, 경계 너머를 꿰뚫어보기 |
| **연(緣)** | 연 | 사람과의 교감, 설득, 위로, 인연 맺기 |

캐릭터 생성 시 네 능력치에 **+2, +1, +1, 0** 을 배분합니다. (최소 −1 ~ 최대 +3)

## 3. 액션(행동) 목록

굴릴 때 "어떤 능력치로?"가 헷갈리면 아래 액션에 대입하세요.

| 액션 | 능력치 | 상황 |
|------|--------|------|
| **맞서다** | 체 | 물리적 위협에 몸으로 맞선다. 부분성공 시 피해/노출을 감수. |
| **파헤치다** | 지 | 단서를 조사·분석한다. 성공 시 GM에게 질문 1개(부분성공은 대가 후). |
| **꿰뚫어보다** | 감 | 경계 너머를 감지한다. 박명체의 정체·약점·미련을 읽는다. |
| **다가서다** | 연 | 상대(사람/박명체)의 마음에 다가간다. 달래기·설득·위로. |
| **경계를 넘다** | 특수 | 초자연 힘을 쓴다. **반드시 침식이 오른다.** (아래 5장) |

### 「파헤치다」 질문 예시 (성공 시 택1)

- 여기서 실제로 무슨 일이 있었나?
- 이 박명체가 원하는 것은?
- 무엇이 겉보기와 다른가?
- 이 위험을 피하려면 무엇을 조심해야 하나?

## 4. 상태와 피해

HP 같은 수치 대신, 가벼운 **상태(Condition)** 로 다룹니다.

- 피해를 입으면 상태 하나를 얻습니다: 예) *다침, 겁먹음, 지침, 혼란, 홀림*.
- 관련 판정에 해당 상태가 방해되면 **−1**.
- 상태는 **휴식·치료·위로**로 지웁니다. 같은 상태를 3개 이상 동시에 안으면 그 장면에서 **탈락**(기절/도주/무력화)합니다.
- 죽음은 드뭅니다. 이 게임에서 진짜 무서운 소모는 HP가 아니라 **침식**입니다.

## 5. 침식(侵蝕) — 이 게임의 심장

각 PC는 **침식도(0~10)** 를 가집니다. 시작값 **1**.

### 침식이 오르는 때

- **「경계를 넘다」** 로 초자연 힘을 쓸 때마다 **+1**.
- 강한 저편의 존재에 노출되거나, 무리하게 힘을 쓰면 GM 판단으로 **+1~2**.
- 「경계를 넘다」 판정:
  - **10+**: 힘이 뜻대로 발현. 침식 +1.
  - **7–9**: 발현되나 대가. 침식 +2, 혹은 침식 +1 & 부작용.
  - **6−**: 힘이 폭주·역류. 침식 +2 & GM이 상황 악화.

### 침식 단계 효과

| 침식도 | 상태 | 효과 |
|--------|------|------|
| 0–3 | **또렷함** | 정상. 「경계를 넘다」에 페널티 없음. |
| 4–6 | **흐릿함** | 이쪽 감각이 무뎌지기 시작. 일상 판정(체·지·연) 중 하나에 가끔 −1. 초자연 감지(감)는 +1. |
| 7–9 | **저물녘** | 위험. 매 세션 시작 시 "잃어가는 것"을 하나 묘사(맛·이름·얼굴 등). 감 +1이지만 인간관계 판정 −1. |
| 10 | **넘어감** | 그 PC는 박명체가 되어 저편으로 넘어간다. **플레이어는 새 캐릭터를 만들거나, GM과 협의해 '넘어간 자'로서 최후의 장면을 연출한다.** |

### 침식을 낮추는 법 — 인연

인연(다음 장)을 통해서만 침식을 **−1** 할 수 있습니다.

- 세션 중 **인연 상대와 진심 어린 교감 장면**을 완결하면 침식 −1.
- 인연을 위해 위험을 감수하거나 비밀을 나누면, 세션 종료 시 침식 −1.
- 인연을 **저버리면(배신·방치)** 오히려 침식 +1.

## 6. 인연(緣)

각 PC는 시작 시 **인연 2개**를 정합니다. 각 인연에 상대와 한 줄 관계를 적습니다.

- 예: *"편의점 야간 알바 동료 — 그 애만은 이 밤일에 끌어들이고 싶지 않다."*
- 인연은 침식의 **닻**이자, 사건의 **불씨**입니다. GM은 인연을 사건에 엮습니다.
- 세션마다 인연 하나에 **초점 장면**을 최소 1회 주는 것을 권장합니다.

## 7. 특기(特技) 2개

각 PC는 각성과 함께 얻은 사소한 초자연 재능 또는 살아온 배경에서 온 특기를 **2개** 고릅니다.
관련 판정에 **+1**, 또는 특정 「경계를 넘다」를 가능하게 합니다. 예시:

| 특기 | 효과 |
|------|------|
| **잔향 읽기** | 물건·장소에 남은 기억의 잔향을 본다. (감 +1) |
| **문지기** | 짧은 시간 경계의 틈을 열거나 닫는다. (경계를 넘다) |
| **말의 온도** | 흥분한 상대·박명체를 말로 가라앉힌다. (연 +1, 달래기) |
| **밤눈** | 어둠·안개 속에서도 또렷이 본다. 은신·추적 (감/체 +1) |
| **응급술** | 다친 상태를 하나 지운다. (지, 1장면 1회) |
| **끈질김** | 탈락 판정을 한 번 버틴다. (체, 세션 1회) |

> 자작 특기 환영. "가볍고, 만능이 아니며, 대가가 있다"만 지키세요.

## 8. 캐릭터 생성 요약 (5단계)

1. **컨셉 한 줄**: 낮의 직업 + 각성 계기. (예: "야간 편의점 알바생, 강물에 빠졌다 살아난 뒤부터 보인다.")
2. **능력치** 배분: +2 / +1 / +1 / 0
3. **특기** 2개 선택(또는 자작)
4. **인연** 2개 작성
5. **시작값**: 침식 1, 상태 없음. 이름·외양·소지품 몇 개.

## 9. 경험과 성장

세션 종료 시 아래마다 **경험 1점**:

- 판정에서 **실패(6−)** 했을 때 (그 자리에서 즉시 1점)
- 인연에 초점을 맞춘 장면을 완결했을 때
- 사건을 '퇴치'가 아닌 **이해·화해**로 풀었을 때
- 세션 마무리 질문에 답했을 때 (GM가 2~3개 제시)

경험 **5점**마다 성장 1회: 능력치 +1(최대 +3) / 새 특기 1개 / 인연 1개 추가 / **침식 −1** 중 택1.
