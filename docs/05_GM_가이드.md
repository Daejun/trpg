# GM 가이드 — 운영 · 안전 · 즉흥 도구

## 안전 장치 (세션 0에서 합의)

현대·초자연물은 죽음·상실·정신적 압박을 다룹니다. 모두가 안전하게 즐기기 위한 최소 장치:

- **X 카드**: 누구든 특정 묘사가 불편하면 "X" 한 마디로 그 장면을 되감거나 건너뛴다. 이유 설명 불필요.
- **라인과 베일**:
  - *라인(선)* = 게임에 절대 등장하지 않을 것. (예: 아동 대상 위해, 특정 실제 트라우마)
  - *베일(장막)* = 등장하되 "화면 밖"으로 처리할 것. (예: 자세한 자해 묘사)
  - 세션 0에서 각자 익명으로라도 적어 공유.
- **정박 확인**: 무거운 장면 뒤 GM이 "잠깐, 다들 괜찮아요?" 하고 한 박자 쉰다.

## GM의 기본 동작(Move)

플레이어가 실패하거나, 굴릴 필요 없이 상황을 진전시켜야 할 때 아래에서 고릅니다.

- 위협을 눈앞에 들이민다 / 대가를 요구한다 / 나중의 화를 예고한다
- 그들의 인연을 사건에 끌어들인다 / 선택을 강요한다(둘 다 아플 선택)
- 세계가 어떻게 반응하는지 보여준다 / 진실의 조각을 흘린다
- **침식을 올릴 문을 연다** (초자연으로만 풀리는 상황을 제시)

> 원칙: **주사위가 나쁘게 나올수록 이야기는 흥미로워진다.** 실패를 벌이 아니라 전환점으로.

## 사건 만들기 템플릿 (5분)

새 박명체 사건이 필요할 때 아래 5칸만 채우세요.

1. **현상**: 사람들이 목격하는 이상한 일 한 줄. (오지 않는 막차, 비치는 다른 도시…)
2. **정체**: 그 뒤의 박명체는 무엇인가.
3. **미련**: 이 존재가 이승에 남은 감정/소원 한 줄. ← 가장 중요
4. **대가**: 방치하면 무슨 일이? 힘으로 풀면 침식은 어떻게?
5. **인연 고리**: 어느 PC의 인연을 여기에 엮을 것인가.

## 침식 페이싱 가이드

- **이상적 곡선**: 1막 종료 시 평균 3~4, 2막 종료 시 5~7, 3막 클라이맥스에서 7~9의 아슬함.
- 너무 빠르면: 인연 초점 장면을 늘려 침식 −1 기회를 준다.
- 너무 느리면: "초자연으로만 풀리는" 위기를 배치해 「경계를 넘다」를 유도한다.
- 진행 도구 캐릭터 시트로 매 세션 전원 침식도를 기록해 두면 곡선이 보입니다.

## 즉흥 표

### 심야 사건 씨앗 (2d6)
| 2d6 | 씨앗 |
|-----|------|
| 2 | 사라진 골목이 하룻밤 다시 나타난다 |
| 3 | 모두가 같은 얼굴을 잊는다 |
| 4 | 편의점 CCTV에 없는 손님이 찍힌다 |
| 5 | 강에서 20년 전 방송이 흘러나온다 |
| 6 | 특정 시간에만 열리는 문 |
| 7 | 죽은 이의 문자가 도착한다 |
| 8 | 거울/유리에 다른 도시가 비친다 |
| 9 | 잃어버린 물건이 저편에서 돌아온다 |
| 10 | 노래를 들은 이가 이름을 잊는다 |
| 11 | 비 오는 밤에만 나타나는 승객 |
| 12 | 도시 한 구획이 저편에 잠긴다 |

### 부분 성공(7–9) 대가 (2d6)
| 2d6 | 대가 |
|-----|------|
| 2–3 | 시간이 걸려 상황이 악화된다 |
| 4–5 | 소음·흔적을 남겨 주목받는다 |
| 6–7 | 상태 하나를 얻는다(다침/겁먹음/지침…) |
| 8–9 | 원하는 것 대신 다른 정보/결과만 얻는다 |
| 10–11 | 인연 중 하나가 위험에 노출된다 |
| 12 | 침식 +1 (힘이 새어 나갔다) |

## 세션 마무리 질문 (경험용, 2~3개 고르기)

- 오늘 누군가의 미련을 이해했는가?
- 인연을 위해 무엇을 감수했는가?
- 힘의 대가로 무엇을 잃었는가(침식)?
- 다음에 반드시 돌아가야 할 곳은?

## 톤 유지 치트

- **일상 8 : 초자연 2** 의 화면 비율. 초자연은 일상을 배경으로 삼을 때 더 서늘하다.
- 괴물의 '무서움'보다 사연의 '쓸쓸함'을 노려라.
- 승리는 대개 '퇴치'가 아니라 '배웅'이다.
