# (보존) 『박명(薄明): 경계의 도시』

현대 한국 도시를 배경으로 한 **일상 + 초자연** 장편 TRPG 캠페인 패키지입니다.
평범한 사람들이 어느 날 '경계 너머'를 보게 되면서, 낮에는 각자의 삶을,
밤에는 초자연 사건을 다루는 **야경(夜警)** 이 되어가는 이야기를 다룹니다.

> "세상에는 두 개의 시간이 겹쳐 있다. 해가 진 뒤에도, 해가 뜨기 전에도.
> 그 얇은 틈을 우리는 박명(薄明)이라 부른다."

## 진행 도구 사용법

`tools/index.html` 파일을 브라우저에서 열기만 하면 됩니다. 설치·인터넷 불필요.

- **주사위**: 2d6 + 수정치를 굴려 성공/부분성공/실패를 자동 판정
- **캐릭터 시트**: 능력치·침식도·인연·특기를 입력하면 브라우저에 자동 저장
- **세션 트래커**: 단서·NPC·진행 로그를 GM이 한 화면에서 관리

## 빠른 시작 (5분)

1. `docs/00_시작하기.md`를 읽는다.
2. `tools/index.html`을 열어 각자 캐릭터를 만든다.
3. `docs/03_캠페인_아크.md`의 **세션 1: 「늦은 배웅」** 으로 첫 게임을 시작한다.

## 인원 · 시간

- **인원**: GM 1명 + 플레이어 3~4명 (권장)
- **세션 길이**: 회당 2.5~3.5시간
- **전체 분량**: 세션 0 + 15세션 (약 4~6개월, 격주 기준)
- **난이도**: 초보 GM·플레이어도 진행 가능 (규칙 가벼움)
